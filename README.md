# GRIT Pro downloads

Official Windows installers and signed software updates for GRIT Pro by FieldTalk.

## Install

Open [the latest release](https://github.com/dartsland/grit-releases/releases/latest), download the Windows x64 .msi installer, close GRIT, then run the installer. This is an alpha release for feedback. Windows may ask administrator permission.

## Update

The connected installer checks for published updates inside GRIT. When Update available appears, click Update. GRIT waits for saved edits, verifies the signed installer, installs and reopens. A GitHub account is not needed to download or update.

Original photos stay at their existing paths. Referenced drives must remain available. Keep backups of your originals and catalog.

Mac/Linux public installers are not available yet. Canon CR2 is supported in the current 8-bit sRGB editing pipeline; other RAW/HEIC workflows, full color management, layers/healing, invisible watermarking and online copyright monitoring need further work.

Release files include installer signatures, SHA-256 checksums, and complete LGPL RAW-helper sources/dependency licenses. SHA-256 checksums detect file changes; GRIT independently verifies publisher signatures for in-app updates.

This repository contains release downloads, not the private application source or user photos.
